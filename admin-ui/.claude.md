# Admin UI — Next.js 16

## Stack
- Next.js 16.2.6, App Router, TypeScript strict
- Node.js 22.22.2
- Keycloak auth via next-auth with Keycloak provider
- shadcn/ui + Radix UI + Tailwind CSS 4
- TanStack Table v8, cmdk (command palette), lucide-react

## Structure
- `app/(auth)/`        — Login, Keycloak callback
- `app/dashboard/`     — Overview KPIs and alerts
- `app/users/`         — User lookup and management
- `app/merchants/`     — Merchant onboarding
- `app/rules/`         — Rule list + create flow (7 rule types)
- `app/segments/`      — Segment list, behavioural builder, upload
- `app/limits/`        — Per-tenant limit config
- `app/pricing/`       — Per-tenant pricing config
- `app/redemption-rates/` — Points→fiat conversion rates for internal redemption
- `app/tenants/`       — Tenant management
- `app/audit/`         — Read-only audit log + diff viewer

## Rules
- All API calls to backend go through `/api/` route handlers or server actions — never expose backend URL to browser
- Use server components by default — client components only when interactivity is required
- Form submissions use server actions
- Auth: protect all routes with Keycloak session check in `middleware.ts`
- Dark mode default; light opt-in via system preference
