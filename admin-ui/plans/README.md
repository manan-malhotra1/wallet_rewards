# Animation improvement plans — admin-ui

Generated by the `improve-animations` skill against commit **c2e8746**. Each plan is self-contained: exact files, current-code excerpts, target values (pulled from the audit catalog — never approximated), and a feel-check. Any agent (or a cheaper model) can execute one without further context.

## Recommended execution order

1. **001** and **002** first — the two HIGH wins (kill the 1500ms chart replay; add reduced-motion). Independent of each other; do both.
2. **005** — scope the pending dim so refetches stop flashing the page.
3. **003** and **004** — the two `transition-all` fixes (button press feedback; GPU wallet indicator). Independent.
4. **006** — define motion tokens (optional consolidation; nothing else depends on it landing, but it gives future work one source of truth).
5. **007** — additive crossfades. Apply **last**, and only after 001 (so fades don't stack on Recharts' animation) and 002 (reduced-motion gate). Skip if the dashboard already feels crisp — see that plan's author note.

## Dependencies

- **007 depends on 001** (crossfade would stack on the 1500ms chart animation) and **002** (reduced-motion gate).
- **003 / 004 / 005** each reference reduced-motion behavior covered globally by **002**; apply 002 first so their press/transform transitions are auto-gated for reduce-motion users.
- **006** is referenced by (not required for) 003/004/005 — those plans currently inline their literal values, so 006 can land before or after.
