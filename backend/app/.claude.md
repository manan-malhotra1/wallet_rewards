# app/ — FastAPI Application

## Entry point
`main.py` registers all module routers and global middleware.

## Module pattern
Each module under `modules/` must have:
- `router.py`   — FastAPI APIRouter with route definitions
- `service.py`  — All business logic, calls to DB and Kafka
- `schemas.py`  — Pydantic v2 models for request/response

## Shared
- `shared/models/`   — All SQLAlchemy ORM models (one file per domain)
- `shared/schemas/`  — Shared Pydantic types used across modules
- `shared/exceptions/` — Custom `HTTPException` subclasses
- `shared/utils/`    — Helpers: hashing, token generation, pagination, PII masking

## Dependency injection
- `database.py` provides `get_async_session()` — use in all route dependencies
- `dependencies.py` provides `get_current_user()`, `get_current_admin()`, `get_current_tenant()`

## Do not
- Do not import one module's service into another — use events or shared utils
- Do not use synchronous DB calls — always async
- Do not hard-code `tenant_id` — always resolve from token context
