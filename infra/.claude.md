# Infra — Local Docker Compose

## Services
- `kafka` + `zookeeper` — Local Kafka broker
- `keycloak`            — Identity provider (admin UI at :8080)
- `redis`               — Celery broker + cache

## Start all services
```bash
docker compose up -d
```

## Kafka topic setup
```bash
bash kafka/topics.sh
```

## Keycloak setup
- Import realm: `infra/keycloak/realm-export.json`
- Admin console: http://localhost:8080
- Realm: `wallet-platform`
- Clients: `admin-ui`, `backend-service`

## Ports
- Kafka: 9092
- Keycloak: 8080
- Redis: 6379
- PostgreSQL: 5432 (local, not Docker)
