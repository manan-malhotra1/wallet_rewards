# Sasai Wallet — Local Docker Compose

Every external service the platform depends on at dev time runs in Docker
out of this directory. **No standalone Postgres / Redis / Keycloak / Kafka
on the host.** Bring everything up with one command from here.

## Services

| Service | Purpose | Host port |
|---|---|---|
| `postgres` | Source of truth (wallets, ledger, audit, identity) | 5432 |
| `kafka` + `zookeeper` | External event ingestion + reward firings | 9092 |
| `keycloak` | Admin identity provider; powers next-auth in admin UI | 8080 |
| `redis` | User session tokens, OTP rate limits, lockout state | 6379 |

## Start everything

```bash
cd sasai-wallet-infra
docker compose up -d
```

First boot takes ~30s while Keycloak initialises its embedded H2 database
and Postgres runs the init script. Watch readiness with:

```bash
docker compose ps
docker compose logs -f postgres keycloak
```

## One-time bootstrap

```bash
# 1. Provision the Keycloak realm + clients
python ../scripts/bootstrap_keycloak.py

# 2. Apply backend migrations
cd ../backend && alembic upgrade head

# 3. Create Kafka topics
bash ../sasai-wallet-infra/kafka/topics.sh

# 4. Seed sample tenants / users / accounts
cd ../backend && make seed
```

## Volumes

- `postgres-data` — wallet + wallet_platform_test DBs
- `keycloak-data` — embedded H2 + realm state
- `redis-data` — session / lockout state (`--appendonly yes`)

Wipe everything: `docker compose down -v`

## Container names

Compose names containers after the project (the directory name):

- `sasai-wallet-infra-postgres-1`
- `sasai-wallet-infra-kafka-1`
- `sasai-wallet-infra-keycloak-1`
- `sasai-wallet-infra-redis-1`
- `sasai-wallet-infra-zookeeper-1`

The Kafka topic-creation script (`kafka/topics.sh`) defaults
`KAFKA_CONTAINER` to `sasai-wallet-infra-kafka-1`. Override with the env
var if you run compose with a different project name.
