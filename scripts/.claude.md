# Scripts — Developer Utilities

## `check_migrations.py`
Runs `alembic check` to verify all model changes have a corresponding migration.
Must pass before any commit that touches `shared/models/`.
CI runs this automatically.

```bash
python scripts/check_migrations.py
```

## `seed.py`
Seeds local database with:
- One default tenant (wallet mode, ZAR)
- Admin user and test users with identifiers
- Sample rules (milestone P2P, streak, first-time top-up)
- Sample tiers (Bronze, Silver, Gold)
- Sample badges

```bash
python scripts/seed.py
```

## Running via make

```bash
make seed       # runs seed.py
make check      # runs check_migrations.py
make dev        # starts uvicorn with reload
```
